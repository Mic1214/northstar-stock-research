# Northstar Stock Research

Northstar is a beginner-friendly stock research and learning website. It is being built in small, testable stages.

## Current status
- Dark-mode responsive interface
- Market Overview, Stock Research, Analysis Lab, Learning Center, Portfolio, and Daily Report sections
- No real market data is connected yet; the site does not show fabricated prices or news

## Run locally
Open `index.html` in a modern browser. No build step or API key is needed.

## Safety and accuracy
This project is educational and is not investment advice. Future financial data must include sources and timestamps, and uncertain explanations must be labeled.
